# Contributing

Read [`CONTRIBUTING.md`](https://github.com/tlockney/tabula/blob/main/CONTRIBUTING.md) and [`AGENTS.md`](https://github.com/tlockney/tabula/blob/main/AGENTS.md) first.

- Work is split into packets in [`docs/packets/`](https://github.com/tlockney/tabula/tree/main/docs/packets). Each names what to read and how to check it is done. One GitHub issue tracks each packet.
- `make setup` and `make check` are the only build entry points, locally and in CI.
- Decisions are recorded as ADRs in [`docs/decisions/`](https://github.com/tlockney/tabula/tree/main/docs/decisions).
- The project is built clean-room. Contributors work from this repository only.

Report bugs and ask questions in [GitHub issues](https://github.com/tlockney/tabula/issues).
