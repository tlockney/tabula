# P5.4: Log viewer and live log stream

| Behavior | Source | Packet |
| --- | --- | --- |
| The app's own log and the dashboard's JavaScript console are kept in a bounded buffer on the device and in HA | F-MGT-06 | P5.4 |
| A log subscription streams the buffer live, batched under the protocol's interval and frame size, filtering at a minimum level | F-MGT-06 | P5.4 |
| The subscription stops on request, on reconnect, and by itself after its TTL with no refresh | F-MGT-06 | P5.4 |
| Credentials and URL query strings are removed from a line before it is buffered (Authorization, access_token=, authSig=, refresh_token) | F-MGT-06 | P5.4 |
| The Tabularium's Logs tab shows the buffer newest- or oldest-first, with level, tag and text filters, follow/pause, a streaming indicator with the expiry, clear (the view only) and a text download | F-MGT-06 | P5.4 |
| Console lines read apart from the app's own lines | F-MGT-06 | P5.4 |
| An offline device shows its buffered lines with when it was last seen, and streaming is disabled | F-MGT-06 | P5.4 |
