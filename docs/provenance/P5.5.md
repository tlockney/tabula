# P5.5: The Tabularium Activity tab

| Behavior | Source | Packet |
| --- | --- | --- |
| The Activity tab shows the device's latest capture from its image entity, with the time of the last capture from the timestamp sensor | F-MGT-07, F-HA-12 | P5.5 |
| A tablet whose image entity holds no image shows the placeholder with a note that the screen was off or nothing has been captured yet, and a tablet that has never captured says so | F-MGT-07 | P5.5 |
| The capture is captioned with the device's reported screen state: screen on or off, the screensaver and its mode, and the current page | F-MGT-07 | P5.5 |
| A capture button presses the existing capture button entity, shows a pending state until the image entity changes, and after 20 s says the capture is still running instead of spinning | F-HA-12 | P5.5 |
| The tab lists the device's command buttons by their entity names and presses them through HA, showing the outcome HA returns, including its error text verbatim | F-MGT-08, F-HA-08 | P5.5 |
| Restart and clear cache are shown as configuration actions, apart from the benign commands, and clear cache is described as removing the dashboard's stored data on the tablet | F-MGT-08 | P5.5 |
| A button whose entity is unavailable is disabled with the reason: the tablet is offline, or the entity is unavailable in HA | F-MGT-08, F-HA-02 | P5.5 |
| A tablet without the screenshot capability shows an explanation instead of an image or a capture button | F-MGT-07 | P5.5 |
| The tab follows the entities from the states HA pushes and never polls; an offline tablet's capture is marked as from its last connection | independent design (plan 5.9) | P5.5 |
