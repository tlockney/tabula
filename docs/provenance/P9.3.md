# P9.3: Intercom call engine in the app

| Behavior | Source | Packet |
| --- | --- | --- |
| A tablet rings when HA sends it a call, shows who is calling, and answers with two-way audio only when someone answers, declines or the ring limit passes; a call ringing in an empty room ends by itself within a minute | independent design, ADR 0025 decision 1, ADR 0028 guards 1, 2 | P9.3 |
| A tablet can start a call or a broadcast from its own screen, choosing a tablet or an area by name, and HA decides who is rung; a tablet whose microphone is unavailable cannot start one | independent design, ADR 0025 decision 6, PROTOCOL.md 4.5 | P9.3 |
| A broadcast plays on its receivers without being answered and keeps their microphones closed; the sender only sends, and its screen reports that it is broadcasting | independent design, ADR 0025 decision 2 | P9.3 |
| A tablet that cannot capture still hears calls and broadcasts, answering with its record path disabled, so a lost microphone never costs the household the ability to be reached | independent design, ADR 0028, "Listen-only" | P9.3 |
| Every call ends by itself at the hard call limit, whether or not anyone is listening, so a call feeding back cannot run unattended for an hour | independent design, ADR 0028 guard 2 | P9.3 |
| A call can be ended from HA in every state — ringing, connecting, in a call or broadcasting — and the tablet stops without a person touching it | independent design, ADR 0028 guard 3 | P9.3 |
| A call ends if the tablet loses its link to HA for longer than the connection's own liveness window, so no call can outlive HA's ability to stop it | independent design, ADR 0028 guard 3 | P9.3 |
| A call that was up when a tablet restarted is gone after the restart: the tablet starts idle and reports idle instead of resuming | independent design, ADR 0028 guard 4 | P9.3 |
| A call holds a partial wake lock and a Wi-Fi high-performance lock for its lifetime, released when it ends, so the call keeps carrying audio with the panel off | independent design, ADR 0028 | P9.3 |
| The wake-word detector releases the microphone while a call that captures is up and re-acquires it when the call ends; a call that only listens, or a broadcast being played, does not take it | independent design, ADR 0029 item 3, ADR 0030 item 7 | P9.3 |
| A tablet says it can take part in a call when it registers, and says it can speak only while it actually holds the microphone | independent design, ADR 0025 decision 7, PROTOCOL.md 4.2 | P9.3 |
| A second call offered to a tablet that is already in one is refused rather than answered, so the caller learns the tablet was busy instead of ringing into a call that cannot start | independent design, PROTOCOL.md 4.5 | P9.3 |
