# P9.6: Voice-started intercom calls

| Behavior | Source | Packet |
| --- | --- | --- |
| Saying "call the kitchen" to a satellite tablet starts a two-way intercom call from that tablet to the room's tablet, speaking "Calling Kitchen." back, and the callee rings with the caller's ids and mode `call` | independent design, ADR 0025 decision 8, ADR 0036 | P9.6 |
| A tablet can be called by its own name ("call Kitchen Kiosk") whether or not it is in an area | independent design, ADR 0036 decision 6 | P9.6 |
| A name the household wrote down in the integration's options ("Intercom names") can be spoken instead of a room, and a person maps to one area or one tablet; the person wins over an area of the same name, and the reply uses the spoken name | independent design, ADR 0036 decision 6 | P9.6 |
| A room holding more than one tablet, an unknown name, a tablet that cannot call and a room in the caller's own area are each answered with a spoken sentence and start no call, so a request never fails silently | independent design, ADR 0025 consequences, ADR 0036 decisions 5, 6 | P9.6 |
| A call is started only from the tablet that heard the request; a request from a device that is not a paired tablet is refused out loud, and no sentence can name another caller | independent design, ADR 0036 decision 4 | P9.6 |
| "Broadcast", "intercom broadcast", "call everyone" and "call everybody" start a live one-way broadcast to every other tablet that can hear, speaking "Broadcasting." back | independent design, ADR 0025 decision 2, ADR 0036 decision 8 | P9.6 |
| A spoken message after "broadcast" stays Home Assistant's own announcement, played through the tablets on the existing announce path, so the two meanings of the word never compete | independent design, ADR 0036 decision 8 | P9.6 |
| The phrases exist only while at least one tablet reports both that it can hear and that it can carry a call; they appear when such a tablet registers and go away when the last one stops, without a restart | independent design, ADR 0036 decision 3 | P9.6 |
| The options flow opens a menu offering the per-tablet settings or the intercom names, and the names are entered as a list, validated on save with every problem listed rather than stored and ignored | independent design, ADR 0036 decisions 6, 7 | P9.6 |
