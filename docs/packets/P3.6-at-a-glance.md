# P3.6 — At a Glance row

Side: build   Tier: standard   Depends on: P3.5
Verification: hardware
Issue: TBD
Status: ready

## Why

F-AAG-01 to F-AAG-04: a row of a few entity states drawn on the screensaver for checking things in passing — doors, locks, garage. It is the first consumer of the P3.5 entity data connection, and it introduces the on-device rendering of HA icons, which the weather/forecast/entity widgets (P3.11) reuse.

Night mode is consumed through the `NightState` flag pre-committed by P3.1's ADR 0002 extension (never-night default), so this packet does not wait on P3.4's hardware-dependent spike; whichever of P3.4 and P3.6 merges last wires the real flag.

## Do

1. Icon rendering, decided in an ADR first: how a device renders an HA entity's icon (`mdi:…`) offline. The Companion app bundles the MDI font; if Tabula bundles it, record the font's license and attribution. The fallback (no icon: the domain's initial) must be defined.
2. The row (F-AAG-01): user-defined order from the settings list, placement per mode (centered on black, under the date on the clock, near the bottom over photos/website later), wrap onto two lines in portrait, text shrinking before name truncation, not drawn on the calendar mode (not built yet; the exclusion still lands now).
3. Appearance (F-AAG-02): icon, name, value; contrasting pill unless the plain style is chosen; icon background reflects active/inactive state as HA tiles do; text color never changes with state; hide-names, monochrome-icons, scale, font options.
4. Formatting (F-AAG-03): HA icon if set else the domain default; states capitalized as HA presents them; numeric states rounded to HA's display precision with unit; empty values drop out; unknown/unavailable still show.
5. Night mode: consume the `NightState` flag pre-committed by P3.1's ADR 0002 extension (never-night default). The row hides when night is active and the hide-overlays option says so, and otherwise uses the night color. Whichever of P3.4 and P3.6 merges last wires the real flag; the never-night default keeps the row honest until then.
6. JVM tests with a fake entity feed: ordering, placement, formatting, drop-out, unavailable, night behavior.
7. `tools/device/check_p36.sh` and a DEVICE.md section.
8. `PROVENANCE.md` rows.

## Out of scope
